# Chapter 5 Quiz

Practice quiz for ITDS231 Computer Networks, Chapter 5 (network layer control plane).

- 7 sets of understanding-based questions plus a balanced mixed set
- Topics: OSPF, RIP, EIGRP, BGP, SNMP
- Instant feedback with an explanation for every answer, redo missed questions, light/dark theme

Open `index.html` in a browser. No build step.
